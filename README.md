# Finanças da casa (app)

Aplicativo instalável (PWA). Depois de publicado, abre em tela cheia, com ícone próprio e funciona offline.

## Publicar no GitHub Pages

1. No GitHub, crie um repositório novo (ex.: `financas`).
2. Envie **todos os arquivos desta pasta** para a raiz do repositório
   (Add file > Upload files > Commit changes).
3. Vá em Settings > Pages. Em "Branch", escolha `main` e a pasta `/ (root)`. Salve.
4. Em 1 a 2 minutos o endereço aparece: `https://SEU-USUARIO.github.io/financas/`

## Instalar no celular

### iPhone (Safari):
1. Abra a página do aplicativo no **Safari** do seu iPhone.
2. Toque no botão de **Compartilhar** (ícone de quadrado com seta para cima no rodapé).
3. Role as opções e selecione **"Adicionar à Tela de Início"**.
4. Toque em **Adicionar** no canto superior direito.

### Android (Chrome):
1. Abra a página do aplicativo no **Chrome** do seu Android.
2. Toque no menu de três pontos **⋮** no canto superior direito.
3. Selecione **"Instalar aplicativo"** ou **"Adicionar à tela inicial"**.

## Seus dados

- Os dados ficam guardados só no aparelho, em cada navegador/app instalado.
- O modelo publicado vem sem valores. O repositório e a página do GitHub Pages são públicos, por isso nenhum número pessoal foi incluído.
- Para levar seus dados para o app: abra o dashboard antigo, vá em "Backup dos dados" > "Gerar backup", copie o texto e cole em "Backup dos dados" no app > "Restaurar".
- Faça um backup de vez em quando. Se você limpar os dados do navegador, o que está no app é apagado.
